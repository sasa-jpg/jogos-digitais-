AVENTURA DO CARAMELO

Projeto libGDX em Java.

Controles provisórios para teste: setas esquerda/direita movem o Caramelo; ESC pausa. O controle IoT real ainda precisa ser implementado e testado com Arduino e MPU6050.

Mecânica: obstáculos fixos distribuídos no percurso, agente de captura animado atravessando horizontalmente, três vidas e avanço de fase ao alcançar a distância final.

Execute no Windows com: gradlew.bat lwjgl3:run

Observação: esta versão foi modificada no código-fonte, mas a compilação deve ser confirmada no seu ambiente Gradle. A integração física com Arduino não está concluída.
