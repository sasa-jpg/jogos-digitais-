# nome provisorio As Aventuras de (um heroi) Estopinha

### 🎯 Público-Alvo
Crianças em processo de reabilitação física.

### ⚠️ O Problema
Dificuldade de coordenação motora e controle dos movimentos.

### 💡 A Proposta
Transformar exercícios de coordenação motora em uma atividade de jogo, usando o movimento da criança para controlar um personagem.
