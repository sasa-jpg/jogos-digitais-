# As Aventuras de Estopinha

Uma solução gamificada de **reabilitação física** infantil, projetada para transformar exercícios motores repetitivos em um jogo divertido.

## 🎯 Sobre o Projeto
* **Público-Alvo:** Crianças em reabilitação física.
* **Objetivo:** Estimular a **coordenação motora** e aumentar a motivação em atividades que costumam ser cansativas.
* **O Jogo:** Um jogo de **3 fases** onde o jogador controla um personagem para coletar objetos e desviar de obstáculos.

## 🛠️ Tecnologias e Funcionamento
O projeto integra hardware e software para capturar os movimentos reais do usuário:

* **Interface:** Desenvolvida em `libGDX`.
* **Controle:** Feito por **inclinação e movimento** (o teclado não controla o personagem).
* **Hardware (IoT):** Arduino + Sensor MPU6050 (Acelerômetro e Giroscópio).

## 📊 Métricas Avaliadas
O sistema acompanha a evolução da criança através de três pilares:
1. **Precisão** dos movimentos
2. **Velocidade** de reação
3. **Consistência** durante as atividades
